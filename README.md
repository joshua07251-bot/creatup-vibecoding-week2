# CREATUP 크리터스 3기 · 바이브코딩 2강

가구 배치 실험실을 만드는 120분 웹교안입니다. 1강과 같은 크림·오렌지 디자인, 수강생/강사 모드, 단계별 진행표·복사할 AI 요청문·작동 예제·체크·메모·과제·인쇄·PDF를 제공합니다.

## 사용
- index.html: 기본 수강생 화면
- index.html?mode=teacher: 강사 화면
- index.html?mode=student: 명시적 수강생 화면
- handout.html: 수강생용 인쇄 교안
- vibecoding-week2-handout.pdf: 실제 출력·검수한 A4 16쪽 PDF
- 같은 폴더의 HTML·JS·CSS·logo.jpg를 함께 보관하세요. 파일 직접 열기보다 로컬 HTTP나 HTTPS 배포 주소에서 사용하는 것을 권장합니다.

## 예제
직사각형 방과 가구의 cm 치수, 이동/90도 회전, 경계 제한, strict 면적 겹침 경고, 의자 뒤 여유 영역(+Y / 시계방향90도 -X), A/B 독립 로컬 저장·같은 축척 비교, JSON 백업·복원을 지원합니다. 실제 치수는 1cm 단위 정수입니다. 여유 깊이는 0~500cm로 조정할 수 있습니다.

직사각형 방의 배치를 검토하는 예제이며, 실측·자동 최적배치·문 회전·전체 동선·수용인원·접근성·피난·안전 판정을 제공하지 않습니다. 60cm는 수업용 예시이지 법규나 편안함을 보증하는 값이 아닙니다.

## 저장·개인정보
- 배치·메모·체크는 브라우저의 출처별 localStorage에만 보관됩니다. 계정·서버 저장이나 자동 기기 간 공유가 아닙니다.
- 앱은 가구 데이터를 외부로 전송하지 않습니다. 웹 글꼴은 jsDelivr CDN에서 불러옵니다.
- 브라우저 데이터를 지우거나 파일/사이트 출처가 달라지면 기존 저장 내용을 볼 수 없을 수 있습니다. 배치 JSON 백업은 따로 보관하세요.
- 강사 모드는 화면 구분이지 접근 통제가 아닙니다. 공개 소스에 비밀·개인정보를 넣지 마세요.

## 선택적 수업 연동
강사 화면의 수업 연동에서 코드를 만들고 연동을 켠 뒤 수강생 링크를 공유합니다. 탭·펼친 단계·타이머·스크롤 위치만 ntfy.sh 공개 중계로 보냅니다. 배치·가구·메모·체크는 전송하지 않습니다. 코드 소지자는 진행 상태를 볼 수 있으므로 반마다 코드를 바꾸세요. 수강생은 따라가기를 잠시 멈출 수 있습니다. 대규모·다기기 환경은 별도 점검이 필요합니다.

## 교사용 준비
교안 안의 작동 예제는 참고 구현입니다. 수강생이 사용할 AI 도구의 파일 수정·미리보기·저장 동선, 시작용 틀, 단계별 정상복구본은 수업 전에 강사가 별도로 준비·검증해야 합니다. JSON 백업은 예제 사용 편의를 위해 추가했으며 필수 구현 범위는 아닙니다.
